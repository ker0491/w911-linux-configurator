W911键盘配置器

未连接
这个浏览器不能直接访问 USB 键盘。请用桌面版 Chrome、Edge、Brave 或 Opera 打开本页。
用 USB 线连接 W911，然后点“连接键盘”，在列表里选择 “K100 Keyboard”（有些系统显示为 “W911 Pro USB”）。改完点“写入键盘”即可。
Linux 首次使用：需要给浏览器授权（只需做一次）

Linux 默认只有 root 能打开 USB HID 设备。复制下面的命令到终端执行，然后拔插一次键盘：

sudo tee /etc/udev/rules.d/70-w911.rules <<'EOF'
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="b6a4", ATTRS{idProduct}=="4100", MODE="0660", TAG+="uaccess"
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="b6a4", ATTRS{idProduct}=="4101", MODE="0660", TAG+="uaccess"
EOF
sudo udevadm control --reload-rules && sudo udevadm trigger
  • 这条规则只影响 VID b6a4 的 W911，不会影响别的设备。
  • 如果 Chrome 是 Snap/Flatpak 安装的，可能仍被沙箱挡住；请用 deb 版 Chrome。
  • 如果设备列表里没有，先确认 lsusb | grep -i b6a4 能看到它；不行就换一根 A-to-C 线（很多这类键盘用 C-to-C 线不亮）。
  • 配置必须走 USB 线；2.4G / 蓝牙模式只能使用，不能改设置。
只读模式：当前通过 2.4G 接收器连接。 接收器能读设置但不会写入。请换 USB 线，然后 并选择 “K100 Keyboard”。

切到配置 2 之前，建议先点 复制到另一配置：配置 2 如果没设置过，键盘会没有输出。 如果已经切过去没反应，点 配置 1 就能切回来。

未连接 用 USB 线插上键盘，然后点“连接键盘”。

按真实位置排版：左上旋钮（←/→），左下 X/Y/Z 三个按钮；右上摇杆（四方向+中键切换配置），右下滚轮（↑/↓）； 中间 19 个键帽。键帽上只显示它当前设置的功能，不显示印字；键位编号在悬停提示和编辑器里。 灯光切换键在键盘背面，不在正面键区。点击任意控件，或直接按设备上的键来选中。改完点右侧“写入键盘”。
